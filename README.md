## Разработка

После того как вы создали проект и установили зависимости с помощью `npm install` (или `pnpm install`, или `yarn`), запустите сервер разработки:

```sh
npm run dev

# или запустите сервер и сразу откройте приложение в новой вкладке браузера
npm run dev -- --open
```

## Сборка

Чтобы собрать продакшен-версию приложения:

```sh
npm run build
```

Посмотреть собранную версию можно командой `npm run preview`.
